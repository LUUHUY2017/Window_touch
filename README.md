# Window_touch

Ứng dụng Desktop nổi trên màn hình (**Floating Icon Overlay**) bằng C# .NET WPF.

## Tính năng chính
- **Icon Nổi Always-On-Top**: Luôn nổi trên mọi ứng dụng, hỗ trợ kéo thả vị trí mượt mà.
- **Giao diện Trong suốt**: Thiết kế không viền hiện đại, hiển thị avatar hình tròn với hiệu ứng đổ bóng.
- **Menu Bung Nút Chức Năng**:
  - 📷 **Chụp màn hình**: Tự động ẩn cửa sổ, chụp toàn màn hình, lưu file PNG vào `Pictures/Screenshots` và sao chép vào Clipboard.
  - 💻 **Mở Desktop**: Khởi chạy nhanh thư mục Desktop trong Windows Explorer.
  - ❌ **Thoát**: Đóng ứng dụng an toàn.

## Hướng dẫn Chạy ứng dụng

```bash
dotnet run
```
